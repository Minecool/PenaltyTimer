# BTD6 Boss Penalty Timer
## Deprecation
This application will likely be deprecated with the release of v56.0 sometime in August 2026 due to the following addition:
> Boss Penalty Warning: On Bosses, the penalty timer will now flash for 5 seconds right before any penalty time starts counting down. 

## Usage
This is an external application that reads the process memory of BloonsTD6.exe to get the difference between the current frame and the frame that the boss penalty starts.
It is cross-platform for both Windows and Linux and opens a GUI that should (hopefully) stay "on top" so you can see it at all times regardless of your monitor setup and operating system.
